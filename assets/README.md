# Demo image and brand asset

`operations-demo.jpg` was captured from this repository’s local static demo after its visual alignment with the [public Atrium website](https://www.atriumforhotels.com/). It shows the initial in-memory fixtures in `demo/app.js`, with no production session, customer data or network integrations. It is not a screenshot of the production iOS app.

The blue Atrium logo comes exclusively from the already-public [website logo](https://www.atriumforhotels.com/assets/logo-blue.png). Its unmodified PNG is stored at [`demo/assets/atrium-logo-blue.png`](../demo/assets/atrium-logo-blue.png), so the demo remains usable offline with its local assets. The logo remains Atrium branding; the repository’s MIT license does not grant trademark rights.

The interface uses the public brand’s blue and neutral palette, with `Geist`, `Helvetica Neue`, Helvetica and Arial as local font choices. It downloads no fonts or other resources.
